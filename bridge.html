Возможности AURION.

Прототип интерфейса межсетевого обмена USDT между TRON (TRC-20) и BNB Smart Chain (BEP-20). Сервисная комиссия AURION рассчитана для будущей покупки токена AUR.

ДЕМОНСТРАЦИОННЫЙ РЕЖИМ. Это не действующий обменник. Доступна проверка API провайдера. Кошельки, реальные котировки и переводы не подключены. Не отправляйте средства по каким-либо адресам для обмена через эту страницу.

Параметры перевода

На текущем этапе не требуется подключать MetaMask, TronLink или подписывать транзакции.
